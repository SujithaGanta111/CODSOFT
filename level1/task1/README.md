# Task 1 – Portfolio Website

## Description
This is my first task for the CODSOFT internship.  
It is a **personal portfolio website** created using **HTML and CSS**.

## Sections Included
1. **Header:** My name and brief introduction  
2. **About:** Photo and short bio  
3. **Skills:** List of my skills and expertise  
4. **Projects:** Samples of work or projects  
5. **Resume:** Link to download my resume in PDF format  
6. **Contact:** My contact details (email, phone)

## Files
- `index.html` – main HTML page  
- `style.css` – CSS styles for the website  
- `photo.jpeg` – Image used in About section
